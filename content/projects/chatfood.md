## Learning agents by building one

ChatFood is a final project I designed for the University of Tehran's Fall 2024 Natural Language Processing course. It gives students a concrete setting for combining language-model reasoning with retrieval and database-backed actions.

The application is a hypothetical food-ordering service. A useful assistant must handle several kinds of requests: explain food information, recommend available dishes, find restaurant offerings, and check or cancel an order.

## The project structure

The assignment brings together:

- **Knowledge retrieval:** answer food questions from a book corpus using RAG.
- **Recommendations:** connect user preferences with dishes the service actually offers.
- **Tool use:** interact with a SQLite database for order-related actions.
- **Orchestration:** organize agent behavior with LangGraph and present it through Chainlit.

The public repository includes the project brief, database utilities, and a sample solution. Its demonstration is credited to student **Mobin Tirafkan**.

## My contribution

I authored the final-project assignment and supplied runnable backend and database starter code. I also taught a four-hour workshop covering chatbots and agents with LangGraph, LanceDB, and Chainlit.
